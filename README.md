# 💗 Página romántica

Una sorpresa romántica hecha para viajar desde una pantalla de bienvenida hacia un universo lleno de estrellas, planetas, emojis, estrellas fugaces y movimiento.

## Importante

La parte donde aparecía el código fue eliminada. Tu novia verá únicamente la experiencia visual y el mensaje romántico.

- `style.css`
